# rnb 操作文档

本文档面向日常使用，覆盖从启动到编辑、执行、保存、打开资源的完整流程。

## 1. 启动

- 直接启动：rnb
- 打开指定文件：rnb path/to/notebook.ipynb
- 查看帮助：rnb -h 或 rnb --help
- 查看版本：rnb --version

启动后默认进入主界面，状态栏会提示当前模式和关键信息。

## 2. 基本导航

- 上下移动 cell：j / k 或方向键
- 进入当前 cell：Enter
- 退出 cell 编辑：Esc
- 页面滚动：Ctrl-b（上翻）/ Ctrl-f（下翻）

说明：滚动时会自动把焦点同步到当前可见区域对应的 cell。

## 3. 执行代码

- 执行当前 cell：r 或 Ctrl-r
- 执行当前 cell：Ctrl-Enter 或 Shift-Enter
- 执行所有代码 cell：Ctrl-R 或 :ra
- 执行当前及以上：:ro 或 Ctrl-k
- 执行当前及以下：:rb 或 Ctrl-j

## 4. cell 内编辑（Vim 风格）

进入 cell 后支持普通模式与插入模式。

### 4.1 进入插入模式

- i：当前位置插入
- I：行首非空白处插入
- a：当前字符后插入
- A：行尾插入
- o：在当前行下方新开一行并插入
- O：在当前行上方新开一行并插入
- Enter（普通模式）：在当前行下方新开一行并插入

### 4.2 普通模式移动

- h / j / k / l：左下上右
- 方向键：左下上右
- gg：跳到首行
- G：跳到末行

### 4.3 插入模式常用键

- Enter：换行
- Backspace：删除前一个字符
- Delete：删除当前字符
- Esc：回到普通模式

## 5. 文件打开与保存

### 5.1 打开文件

- :open <path>

例如：:open assets/rich_demo.ipynb

### 5.2 保存文件

- :w：保存
- :w <path>：另存为
- :wq / :wq <path>：保存并退出
- :x / :x <path>：保存并退出
- Ctrl-s：快速保存

重要行为：

- 如果当前会话没有已绑定文件路径（例如直接 rnb 启动），执行 :w、:wq、:x 或 Ctrl-s 时会提示你输入保存路径。
- 输入路径后回车即可完成保存。

## 6. 打开链接与图片

### 6.1 打开 markdown 链接

- :ln

如果当前 markdown cell 有多个链接，会弹出选择框，使用 j/k 或上下键选择，回车打开。

### 6.2 打开图片资源

- :img

支持两类来源：

- markdown 中的图片地址
- code cell 输出中的图片数据

同样支持多候选弹窗选择后打开。

系统通过 xdg-open 调用默认程序打开外部资源。

## 7. 内核选择

- :kernel

打开内核选择器后：

- 选择：j/k 或上下键
- 应用：Enter
- 取消：Esc

## 8. 帮助面板

- :h 或 ?
- Esc 关闭

建议首次使用先阅读帮助面板，再结合本文档进行操作。

## 9. 常见问题

### 9.1 为什么图片在终端里看起来不够清晰

终端显示本质上是字符网格渲染，细节会损失。推荐使用 :img 调用系统查看器查看高清图片。

### 9.2 为什么 :ln 或 :img 只显示状态栏提示

当候选数量大于 1 时会出现选择弹窗；如果没有资源会只在状态栏提示无可用项。

### 9.3 为什么第一次保存会要求输入路径

这是为了避免无意写入默认文件名，确保你明确保存位置。

## 10. 推荐工作流

1. rnb 打开或创建会话
2. Enter 进入 cell，使用 i/I/a/A/o/O/Enter 编辑
3. r 或 Ctrl-r 执行当前 cell
4. 用 :ln / :img 打开外部资源
5. :w <path> 首次保存，后续 Ctrl-s 快速保存
